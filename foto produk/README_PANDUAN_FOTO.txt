CARA MEMASUKKAN FOTO ANDA KE DALAM WEBSITE:
--------------------------------------------------------------------------------
1. Buka folder model yang ingin Anda isi (contoh: buka folder "model-01").
2. Salin (copy-paste) foto sepatu jepretan Anda ke dalam folder tersebut.
3. Beri nama file foto Anda seperti ini:
   - foto-1.jpg  -> Foto utama (langsung tampil di katalog & foto utama detail)
   - foto-2.jpg  -> Foto sudut samping / tapak sol empuk (tampil di galeri)
   - foto-3.jpg  -> Foto pemakaian / detail kulit (tampil di galeri)

*Bisa menggunakan format .jpg, .jpeg, .png, maupun .webp.

--------------------------------------------------------------------------------
APA YANG TERJADI JIKA BELUM ADA FOTO?
